# 板布局补录与精简审查（2026-10-14）

## 需求与验收范围

1. 板布局不是必填输入。仪器文件缺少 Sample 列或样本名时，保留测量并提供补录入口。
2. 按用户选中的板及物理孔补全样本名；不能混合不同板上的同名孔。
3. 接受 CNV 布局工具的工作簿、Excel 粘贴两列及下载后填好的模板。
4. 已有样本名、Ct、flags、Omit 和已填写登记不覆盖。重复孔给出不同样本名时拒绝该布局；与仪器已有样本冲突时保留仪器值并提示。
5. 分析前选用的布局可补实验/试剂空白信息；分析后的补录入口只读取孔位/样本信息。
6. 补录映射可随本次登记保存，原始样本名与补录来源进入导出审计。
7. 正常带样本输入与补录输入的样本 CN、QC 输出一致；旧计算公式及科学防错不变。

用户确认的三个测试 seam：所选板孔位补名；文件/粘贴/模板一致且原值不覆盖；登记补空与 CN 计算一致。

## 支持格式

- 工作表包含 `Well` / `Sample` 表头（也接受 `Well Position`、`Sample Name`、`Sample ID`、孔位/样本名等别名）。无表头两列需第一行即为有效孔位。
- 孔位采用 A1–P24，兼容小写与 A01；空白样本行忽略。96 孔与部分使用的 384 孔不依赖固定数据行数。
- `Well Details P01`、`Paste_QS_P01`、`Paste_Legacy_P01` 合并为 P01；同一板的重复同值记录去重。不同 Pxx 保持分离。其他工作表各自视为一板，或使用显式 `Plate` 列。
- 只补仪器结果中存在的孔，不凭布局生成 Ct 或新测量。不把 `Sample 1` 等已有名称自动视为空白。
- 多板时必须手动选板；工具不从文件名、样本数量猜测是哪一板。

### 实验与试剂信息

读取 `Run Summary`、`Reaction Setup`、`Experiment Info` 或中文登记页中的明确字段：板号、实验日期、操作人、反应体积、SOP，以及 Master Mix 名称/品牌/货号/批号/有效期。

`Assay & Dyes`、`Assays`、`试剂信息` 通过 target 匹配；提供 Reporter 时也必须匹配。只有唯一匹配才补品牌、Assay ID、批号、浓度和 Quencher。没有提供的值不推断；不把试剂名称当品牌。日期接受 YYYY-MM-DD 或 YYYY/MM/DD。

实验登记中已有的人工值、本机预设或同文件已保存值均优先。批号/有效期仍需使用者核对，补入信息不代表已完成实验复核。

用户示例文件本地回读识别到 P01、32 个有样本名的孔、10 µL 反应体积与 Master Mix 名称；未将原文件或真实样本 ID 放入测试仓库。

## 本轮精简

| 原设计 | 修改 | 保留边界 |
| --- | --- | --- |
| 登记读取、展示、恢复各维护字段列表 | 共用一份字段映射 | 字段含义与持久化兼容 |
| 每次计算重画所有隐藏页签 | 只绘制当前页签，打印前绘制全部 | 所有结果页与打印功能保留 |
| 标记“未保存”必然撤销复核 | 保存状态与复核失效分开 | 分析或登记改变后仍重新复核 |
| 保存前先 JSON 深拷贝再序列化 | 直接序列化最终保存对象 | 保存结果是独立 JSON |
| 表头识别使用奖励分与魔法分数 | 直接要求孔位、Target、Ct | 缺样本名仍保留测量 |
| 文件解析阶段直接修改运行状态 | 解析成功后一次提交；旧异步读取不覆盖新选择 | 失败提示与上一份有效数据保留 |
| 发布测试再次硬编码资产名单 | 对照 HTML 引用与单一资产清单验证 | 离线/Sites 依赖完整性保留 |

没有引入新依赖、通用导入框架、数据服务器或会话框架。保留内参失败、0-copy 条件、校准资格、NTC 扩增、复孔质量和群体模型门槛，不将科学防错当作冗余删除。
