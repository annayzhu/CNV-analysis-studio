# 板布局补录与精简审查（2026-10-14）

## 需求与验收范围

1. 板布局不是必填输入。仪器文件缺少 Sample 列或样本名时，保留测量并提供补录入口。
   仪器结果导入后停留在准备区，不调用计算或跳转；仪器/布局导入顺序不限，点击“开始分析”才应用所选布局并计算。开始后另换仪器文件也回到准备区，不沿用上一运行的布局草稿。
   导入成功后，大上传区收为文件信息栏，提供“重新选择”和“移除文件”。移除只清空页面中的仪器数据及当前分析，不删除源文件或已保存登记；分析前选择的布局可保留，已用于上一轮分析的布局会清除。替换文件读取失败时保留原有效文件。
2. 按用户选中的板及物理孔补全样本名；不能混合不同板上的同名孔。
3. 接受 CNV 布局工具的工作簿、Excel 粘贴两列及下载后填好的模板。
4. Ct、flags、Omit 和已填写登记不覆盖。重复孔给出不同样本名时拒绝该布局；与已有样本名不同时，按用户后续要求允许确认后覆盖，取消则不变。
5. 分析前选用的布局可补实验/试剂空白信息；分析后的补录入口只读取孔位/样本信息。
6. 补录映射可随本次登记保存，原始样本名与补录来源进入导出审计。
7. 正常带样本输入与补录输入的样本 CN、QC 输出一致；旧计算公式及科学防错不变。

用户确认的三个测试 seam：所选板孔位补名；文件/粘贴/模板一致且原始测量不覆盖；登记补空与 CN 计算一致。后续扩展了样本名覆盖确认、取消、样本重计数及重复修订来源追溯。

## 支持格式

- 工作表包含 `Well` / `Sample` 表头（也接受 `Well Position`、`Sample Name`、`Sample ID`、孔位/样本名等别名）。无表头两列需第一行即为有效孔位。
- 孔位采用 A1–P24，兼容小写与 A01；空白样本行忽略。96 孔与部分使用的 384 孔不依赖固定数据行数。
- `Well Details P01`、`Paste_QS_P01`、`Paste_Legacy_P01` 合并为 P01；同一板的重复同值记录去重。不同 Pxx 保持分离。其他工作表各自视为一板，或使用显式 `Plate` 列。
- 只更新仪器结果中存在的孔，不凭布局生成 Ct 或新测量。不把 `Sample 1` 等已有名称自动视为空白，也不把全板同名自动标为“信息完整”；导入新布局后可确认覆盖。
- 多板时必须手动选板；工具不从文件名、样本数量猜测是哪一板。

### 实验与试剂信息

读取 `Run Summary`、`Reaction Setup`、`Experiment Info` 或中文登记页中的明确字段：板号、实验日期、操作人、反应体积、SOP、Master Mix 名称/品牌/货号/批号/有效期，以及复核人、复核日期、复核说明和实验备注。板布局不自动设置“已复核”或“同意放行”。

`Assay & Dyes`、`Assays`、`试剂信息` 通过 target 匹配；提供 Reporter 时也必须匹配。只有唯一匹配才补品牌、Assay ID、批号、浓度和 Quencher。没有提供的值不推断；不把试剂名称当品牌。日期接受 YYYY-MM-DD 或 YYYY/MM/DD。

实验登记中已有的人工值、本机预设或同文件已保存值均优先。批号/有效期仍需使用者核对，补入信息不代表已完成实验复核。

下载的 `CNV_板布局与实验登记模板.xlsx` 包含 `Samples`、`Run Summary`、`Assay & Dyes` 和 `填写说明`，分表名称和字段兼容 CNV 板布局工具。已导入仪器结果时，模板只预填实际孔位、靶标和 Reporter；编号和填写单元格设为文本格式以保留前导零。第一步导入后点击“开始分析”，实验信息自动补入；分析后的补录入口仍只处理样本孔位。

用户示例文件本地回读识别到 P01、32 个有样本名的孔、10 µL 反应体积与 Master Mix 名称；未将原文件或真实样本 ID 放入测试仓库。

## 样本名修订（后续调整）

页面显示实际样本数和孔数；布局预览只显示简短统计及可滚动的当前/新样本名对照。覆盖时仅进行一次确认，完成后收起编辑区，不再列出整板孔位。缺少 NTC 的提醒留在导出审计中，不重复显示在 QC 卡片。

录入区按“选择来源 → 核对 → 应用”组织：上传与粘贴二选一，粘贴输入框按需显示；桌面上文件操作集中在一行，实验板、变更数量和应用按钮集中在预览表上方一行。窄屏按操作组换行，不逐字段堆叠。

校准文字依据与选择备注为选填，不计入登记缺项；留空不影响计算、人工放行或导出。校准品资格、已知 CN 和独立确认勾选仍保持原规则。已填写的文字仍保留在校准审计中。

`applySamples` 默认只补空，显式 `overwriteExisting=true` 才更新已有名称。浏览器在确认后使用该路径；保存的修订含此标志，可无重复确认地恢复。多次修订始终保留最初的 `originalSampleName`；不在模板中的孔保持原样。

样本分组改变时旧校准不再沿用。按样本名人工指定的 NTC 转为相同物理孔的指定，原文件的 NTC 名称/Task 标记也保留其角色，避免改名悄悄改变实验对照。

## 本轮精简

| 原设计 | 修改 | 保留规则 |
| --- | --- | --- |
| 登记读取、展示、恢复各维护字段列表 | 共用一份字段映射 | 字段含义与持久化兼容 |
| 每次计算重画所有隐藏页签 | 只绘制当前页签，打印前绘制全部 | 所有结果页与打印功能保留 |
| 标记“未保存”必然撤销复核 | 保存状态与复核失效分开 | 分析或登记改变后仍重新复核 |
| 保存前先 JSON 深拷贝再序列化 | 直接序列化最终保存对象 | 保存结果是独立 JSON |
| 表头识别使用奖励分与魔法分数 | 直接要求孔位、Target、Ct | 缺样本名仍保留测量 |
| 文件解析阶段直接修改运行状态 | 解析成功后一次提交；旧异步读取不覆盖新选择 | 失败提示与上一份有效数据保留 |
| 发布测试再次硬编码资产名单 | 对照 HTML 引用与单一资产清单验证 | 离线/Sites 依赖完整性保留 |

没有引入新依赖、通用导入框架、数据服务器或会话框架。保留内参失败、0-copy 条件、校准资格、NTC 扩增、复孔质量和群体模型门槛，不将科学防错当作冗余删除。

## Standards

独立审查发现 1 项板隔离规范问题：初稿会把任意以 Pxx 结尾的工作表合并。已限定为布局工具的三个已知工作表前缀；其他名称保留独立板号。先复现失败，再通过公开 `parseSheets` 测试确认修复。未发现其他可操作的规范违反或需要增加抽象的代码异味。

## Spec

独立审查发现 2 项需求问题：上述板隔离问题，以及试剂页错误地强制要求 Assay ID 列。后者已改为只需识别 Target，可按唯一匹配补入实际提供的品牌/批号等字段；不提供的字段保持空白。两项均有先失败后通过的回归检查；未发现额外越界功能。

审查汇总：Standards 1 项、Spec 2 项（其中板隔离为同一问题），均已修正；当前没有未处理的审查发现。此次只完成本地代码与生成的发布副本，未推送或部署线上站点。
