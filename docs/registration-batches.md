# 登记恢复与试剂批次管理

## 本次需求（2026-10-16）

1. 实验登记保留上次内容，刷新后可继续，不必重新导入仪器文件；新登记日期默认当天，恢复旧记录保留原日期。
2. Master Mix 与各 assay 的试剂批次可以保存、选用、编辑和删除。批次只保存试剂信息，不沿用上次实验的复核结论。
3. 页面减少卡片嵌套，保留主步骤分组，内部用标题、间距与分隔线组织；标题、字段与说明有清楚字号层级，兼容桌面与窄屏。
4. 不改变 CN 数学计算、原始 Ct、QC 规则、已有布局导入及导出格式。

用户确认的验收范围：刷新恢复与当天日期；批次保存/调用/编辑/删除及复核信息隔离；布局精简后计算和导出不变。审查起点为 `cc09a66`。

## 实现说明

浏览器适配层 `app.js` 管理本机存储，不新增后端或状态框架。登记输入后延迟 350 ms 保存，离开页面时补存未完成修改；只保留最近一次分析的规范化输入快照，恢复时重新计算，不持久化一份重复计算结果。已存在的按文件摘要存档仍兼容，最多保留 20 份登记。

新登记在应用可选板布局后补上当天日期，避免盖掉布局已提供的实验日期。当天使用浏览器当地日期，不从 UTC 日期或仪器文件名推断。

试剂批次与单次登记分开存储，按 Master Mix 或 target + reporter 区分。调用批次时复制固定的试剂字段到当前登记，历史登记不会随批次编辑或删除而改变。若当前实验已放行，调用不同试剂信息仍按现有规则撤销签认、等待重新复核。

界面保留主步骤卡片；NTC、校准、登记子区、试剂行和方法说明不再叠加外框。桌面上批次下拉与保存/删除同一行，窄屏按实际宽度换行，导航标签保持单行横向滚动。

## 验证

`scripts/verify-registration-ui.mjs` 只使用合成仪器数据，经实际页面操作和下载文件验证：

- 中国时区跨 UTC 日期时仍显示正确当天日期。
- 未点手动保存就刷新，登记和校准设置仍恢复；移除文件后刷新不恢复，但重新导入仍可取得原登记。
- 两个 Master Mix 批次可独立新增、调用、修改和删除；不同 assay 批次不混用。
- 新仪器运行不继承上一板批号、复核人、复核日期或放行结论。
- 已知 CN=2 校准、样本 ΔΔCt=1 的独立算例保持 CN=1；刷新和批次编辑前后的 JSON 分析内容一致（不比较生成时间）。
- 1440、760、390 px 宽度无整页横向溢出，标题与字段字号层级明确。

同时保留原有浏览器流程验收、计算/导出单元测试和发布资产同步检查。
